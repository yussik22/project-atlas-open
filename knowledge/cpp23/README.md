# Локальна бібліотека рішень C++23 для Project Atlas

Це **не копія стандарту** і не дозвіл вигадувати властивості C++.
Зафіксована версія мови — C++23; основне публічне джерело — [фінальний
робочий проєкт WG21 N4950](https://www.open-std.org/jtc1/sc22/wg21/docs/papers/2023/n4950.pdf).
[Звіт редактора N4951](https://open-std.org/JTC1/SC22/WG21/docs/papers/2023/n4951.html)
підтверджує статус N4950. Код Atlas використовує окремо API Clang 23.1.3:
це **інструментальна реалізація**, а не частина стандарту C++23.
Посилання на `eel.is/c++draft` у картках зручні для пошуку розділів,
але це живий проєкт, який може відображати новішу редакцію; для точного
формулювання саме C++23 звіряйте відповідний розділ N4950.

## Як застосовувати

1. Сформулювати потрібну властивість: наприклад, «один ID для того самого
   класу в різних translation units і між запусками».
2. Відкрити відповідну картку. Відокремити гарантію C++23 від поведінки
   конкретної бібліотеки/компілятора й від нашого рішення.
3. Обрати джерело ідентичності, формат зберігання й межі застосування.
4. Додати контрольний приклад і негативний тест; не покладатися на назву API.
5. Якщо документація не дає потрібної гарантії, позначити припущення і
   не використовувати його як незмінний контракт.

## Шаблон наступної картки

`Питання → вимога до властивості → гарантія C++23 з пунктом N4950 →
контракт зовнішнього API → обране представлення → граничні випадки →
тест, який може спростувати припущення.`

Нова картка має містити точні посилання на первинну документацію,
версію інструмента та місце в коді, де рішення реально використовується.
